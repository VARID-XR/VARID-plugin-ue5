# VARID 2.1 Release Notes

Release date: 12 August 2026

VARID 2.1 focuses on more reliable post-processing in desktop and stereo rendering, safer handling of condition textures, and lower-cost blur generation. This release targets Unreal Engine 5.5 on Win64 with DirectX 12.

## Highlights

- Improved stereo condition handling with separate render-thread state for mono, left-eye, and right-eye views, including side-eye stereo indices. A stereo eye with no condition now falls back to the active mono condition.
- Reworked Gaussian blur pyramid generation to combine filtering and downsampling in one compute pass per mip.
- Reduced blur work for cataracts, hyperopia, myopia, and macular degeneration by generating only the mip levels required by the configured blur strength.
- Moved diabetic retinopathy floater animation and nystagmus offset calculations out of per-pixel shader work and into render-pass setup.

## Fixes and stability

- Added output bounds checks to resampling and Gaussian compute shaders and clamped Gaussian source reads at texture edges.
- Corrected render-target viewport handling for both desktop output and VR override output.
- Fixed maximum mip-level values and clamped blur sampling to generated mip ranges.
- Kept glaucoma scotoma and diabetic retinopathy floater textures referenced while effects are active, and retained ref-counted RHI handles for queued render work.
- Cleared stale texture references when switching to effects that do not use them or when clearing all eye conditions.
- Flushed queued rendering commands before releasing the scene view extension during rendering shutdown.
- Stopped plugin shutdown from resetting shader-source mappings owned by Unreal Engine or other plugins.
- Added a safe fallback when normalized mouse position is requested without an available game viewport.
- When no condition is active, the post-process pass now returns the scene color unchanged.

## Behavior changes

- The default sampler used by the Blueprint `BeginRendering` function is now bilinear sampling instead of Gaussian sampling. Pass `GaussianSampling` explicitly to retain Gaussian pyramid generation.
- Gaussian sampling now uses a dedicated 5x5 filtered downsample, which may produce subtle differences from the previous blur appearance.

## Maintenance

- Updated the plugin version from 2.0 to 2.1.
- Removed an unused Unreal Renderer internal include path and unnecessary broad engine includes.
- Tidied the Meta Quest Pro setup notes and repository ignore rules.

VARID effects are representative visual simulations intended for design, education, and research; they are not clinical or diagnostic tools.
